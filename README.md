# 悬浮小宠物 · 玩具水枪互动

这是一个零依赖的静态网页演示。右下角的小宠物在鼠标悬停、键盘聚焦或点击时，会在身前拿出玩具水枪并喷出水花；鼠标移开或失焦后停止。

## 使用

直接打开 \`index.html\`，或部署到任意静态网站服务。

## 交互与可访问性

- 鼠标：移入开始喷射，移开停止。
- 键盘：Tab 聚焦开始，失焦停止。
- 触摸：点击切换喷射状态。
- 已支持 \`prefers-reduced-motion\`，降低动画强度。

## 参考

交互状态的产品思路参考了 GitHub 项目 [alienmelon/pet_cursor.js](https://github.com/alienmelon/pet_cursor.js) 的“状态式网页小宠物”概念；本仓库的 HTML、CSS 和 JavaScript 均为重新实现，未复制其源代码；小宠物本体使用仓库内的蜡笔小新透明图片。
